# TheHunterClassicRebirth

TheHunterClassicRebirth is an open-source preservation project for **theHunter Classic**.

The goal is to rebuild the online services required by the game so that it can remain playable independently of its original infrastructure.

The project will progressively cover features such as authentication, player profiles, inventory, game sessions, reserves, progression, missions, and the launcher workflow.

## Project status

🚧 **Early development**

The project is currently in its first development phase, focused on understanding the game's client/server communication and rebuilding the core backend services.

## Disclaimer

TheHunterClassicRebirth is an independent community preservation project and is not affiliated with, endorsed by, or associated with Expansive Worlds or Avalanche Studios Group.
